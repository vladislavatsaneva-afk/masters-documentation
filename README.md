# Audio Signal Management System – Documentation

## Overview
This repository contains the documentation and supporting materials for my Master's degree project in Computer Systems and Technologies at the University of Ruse "Angel Kanchev".

It accompanies the source code repository and provides a detailed description of the project's development process.

## Documentation Contents
The documentation covers:
- Research and analysis
- Project planning
- System design and architecture
- Development process
- Testing
- User instructions with provided screenshots of the system
- A short presentation of the project: 'presentation.pptx'

## Repository Structure
- audios folder – audio files used for testing
- diploma folder – main project documentation
- sys_documents folder – supporting technical documents
